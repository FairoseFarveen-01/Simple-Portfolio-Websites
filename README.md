## 📂 Website Structure
The website consists of two core pages designed for smooth user navigation:
* **Home Page (`index.html`):** Introduces who I am, my core skills, and a summary of my work.
* **Contact Page (`contact.html`):** Features a structured layout or form for users to get in touch.

## 🚀 Features
* **Multi-Page Navigation:** Simple, intuitive navigation bar linking the Home and Contact pages.
* **Modern UI/UX:** Clean aesthetic focusing on presentation and readability.
* **Fully Responsive:** Optimised for all screen sizes including smartphones, tablets, and desktops.
* **Pure Styling:** Developed entirely with custom CSS without relying on heavy frameworks.

## 🛠️ Tech Stack
* **HTML5:** Semantic markup for structured web content.
* **CSS3:** Custom layouts, flexbox/grid styling, and navigation links.
