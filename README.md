A simple personal portfolio website built using HTML and CSS, featuring Home and Contact page. 

# 🌐 Personal Portfolio Website

## 📌 About the Project

This is my personal portfolio website created using **HTML5 and CSS3**. 

It is designed to introduce myself and provide a simple way for visitors to connect with me.

The website contains two pages: Home and Contact, with a clean and simple user interface.

## 🛠️ Technologies Used

- HTML5
 
- CSS3

## 📄 Pages Included

- **Home Page:** Introduces me and provides basic information about me.
 
- **Contact Page:** Allows visitors to find my contact information and get in touch with me.

## ✨ Features

- Simple and clean design

- Easy navigation

- Basic CSS styling

- User-friendly interface

- Multi-page website structure


## 🚀 How to Run the Project

1. Clone this repository.

2. Open the project folder.

3. Open `index.html` in your browser.
